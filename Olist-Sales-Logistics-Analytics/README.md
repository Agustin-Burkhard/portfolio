# Olist Sales & Logistics Analytics

Proyecto de análisis de datos desarrollado a partir del dataset público de Olist,
con foco en el comportamiento comercial, la logística de entregas y la experiencia
del cliente.

## Objetivo

Analizar la actividad comercial de Olist para identificar patrones de ventas,
comportamiento de pedidos, desempeño logístico y factores relacionados con la
experiencia del cliente.

## Herramientas utilizadas

- Power BI
- Power Query
- DAX
- Modelado de datos
- ETL
- Análisis exploratorio de datos

## Proceso

El proyecto incluyó:

- Importación y transformación de datos.
- Limpieza y preparación mediante Power Query.
- Construcción del modelo relacional.
- Creación de métricas y KPIs mediante DAX.
- Desarrollo de dashboards interactivos.
- Análisis comercial y logístico.
- Elaboración de conclusiones a partir de los resultados obtenidos.

## Principales análisis

El dashboard permite analizar:

- Volumen y evolución de pedidos.
- Ventas y ticket promedio.
- Distribución geográfica de la actividad.
- Tiempos de entrega.
- Pedidos entregados fuera de término.
- Relación entre logística y experiencia del cliente.
- Comportamiento de las calificaciones.
